# Credit-Score-Prediction-System
📌 Overview
This project predicts customer credit scores and churn probability using machine learning models. It was developed as part of an Artificial Neural Networks course project.

🛠 Tech Stack
Programming Language: Python

Libraries: Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, TensorFlow

Database: SQL (for data storage and preprocessing)

Tools: Jupyter Notebook, Power BI (for visualizations)

📂 Project Workflow
Data Collection: Credit scoring dataset with customer demographics, account details, and transaction history.

Data Preprocessing: Cleaning, encoding categorical variables, handling missing values, scaling numerical features.

Exploratory Data Analysis: Distribution analysis, correlation analysis, and identifying feature importance.

Model Building:

Built ANN model for credit score prediction.

Compared activation functions and applied dropout for regularization.

Evaluation:

Accuracy, precision, recall, and confusion matrix analysis.

Adjusted classification threshold for better churn prediction.
